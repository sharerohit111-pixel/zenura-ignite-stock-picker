# ZENURA IGNITE

**Paper Trading & Paper Investing**

Research-first stock analysis prototype for company fundamentals, financial statements, screening, valuation, comparison, watchlists and research reports.

Founder & Developer: Rohit Kumar

The current release is a static PWA research prototype. The subtitle describes the product direction; it does not mean live brokerage execution or a complete paper-trading simulator is already available. Financial data must be source-attributed and period-aware; missing values must not be represented as zero.

## Development status

See [Feature Status](docs/FEATURE-STATUS.md) and the [Backend, Authentication and Security Plan](docs/SECURITY-AND-BACKEND-PLAN.md).

## Important limitations

- Demo company values are illustrative and must not be treated as real securities data.
- No live NSE/BSE or commodity feed is connected.
- No production login, cloud account sync, or AI research service is deployed.
- Never put provider/API secrets in the static frontend or GitHub repository.
- Ads and paid subscriptions remain disabled by design.
